# Vlk Crash – PWA
Obsah:
- index.html – hra
- manifest.webmanifest – instalace jako aplikace
- sw.js – offline cache
- icons/ – ikony aplikace

Pro instalaci a generování Android balíčku musí být celý obsah zveřejněn na HTTPS adrese.
Doporučená cesta: nahrát obsah do GitHub repozitáře a zapnout GitHub Pages; poté vložit URL webu do PWABuilderu.
